# 小学4-6年级知识题库研发与设计规范文档
（Knowledge Base Architecture & Generation Specification）

---

## 一、题库设计背景与教学目标

针对小学 4 至 6 年级（中高年级过渡与小升初阶段）学生的心理与认知特点，本应用致力于将“碎片化被动刷手机”转变为“高频主动的趣味知识通关”。

题库研发的核心目标：
1. **激发学习兴趣**：拒绝枯燥死记硬背，融入生活化情境、趣味名师拆解口诀；
2. **专项攻克作文薄弱项**：重点突破选材立意、细节刻画、开头先声夺人、修辞手法与古诗文哲理；
3. **夯实数学与思维模型**：聚焦简便速算、几何内角和、因数质数合数、比例尺、植树模型与立体几何倍数规律；
4. **小学核心英语语感化**：提炼小学必考时态（进行时、过去时）、介词口诀、比较级变形与常用交际口语；
5. **支持自适应推荐与在线动态扩充**：构建结构化标签体系，支撑学情薄弱项诊断与云端更新。

## 三、题目数据结构定义 (Schema)

每道题在工程中均遵循规范化设计，包含如下 8 个维度：

```kotlin
data class Question(
    val id: String,                 // 唯一题目ID（如 g4_cn_1, g5_ma_2）
    val grade: Grade,               // 适用年级：GRADE_4, GRADE_5, GRADE_6
    val subject: Subject,           // 学科类型：CHINESE_ESSAY, MATH, ENGLISH
    val title: String,              // 题干（带考点类型标签前缀，如【修辞与作文】）
    val options: List<String>,      // 4个精心设计的干扰项与正确项
    val correctIndex: Int,          // 正确答案索引（0-3）
    val explanation: String,        // 名师深度精析（详细说明为什么选它、排除干扰项的原因）
    val keyPoints: List<String>,    // 核心考点与答题公式提炼
    val sampleEssence: String       // 作文金句积累 / 速算口诀 / 语法记忆法
)
```

## 四、题目生成与命题原则

1. **题干情境化与考点显性化**：
   - 题干统一添加 `【考点类别】` 标签（例如 `【现在进行时】`、`【比和比例应用】`、`【作文开头技巧】`），帮助学生建立清晰的知识树索引。
2. **选项设计的诊断性（Diagnostic Distractors）**：
   - 错误选项并非随意编造，而是针对学生真实常见的易错心理设计：
     - *数学题*：涵盖混淆单位“1”、漏加间隔+1、误把偶数全当合数等经典坑点；
     - *英语题*：涵盖主谓不一致、过去式不规则变化写成规则、介词机械套用等；
     - *作文题*：对比“记流水账开头”与“先声夺人开头”、“空洞口号”与“具体细节描写”，让学生直观体会好文章与平庸文章的差距。
3. **“名师精讲”与“干货金句”双输出**：
   - 每道题目均附带独家的 `sampleEssence`（如写作金句、口诀记忆法），答完题后不仅知道对错，更能沉淀好词好句和解题规律。

## 五、持久化存储与在线更新架构

```
[云端/预设新课标扩展库 (ExpandedQuestionData)]
                    │
                    ▼  (在线更新接口: syncOnlineQuestionBank)
[Room 本地数据库 (AppDatabase -> BankQuestionDao)]
                    │
      ┌─────────────┴─────────────┐
      ▼                           ▼
[通关答题随机构筑 (getRandomQuiz)]  [知识库动态浏览 (getQuestionsForGradeFlow)]
      │                           │
      ▼                           ▼
[自适应学情推荐系统]               [离线优先 & 实时同步]
```

1. **本地数据库初始化**：
   - 应用初次安装启动时，由 `StudyRepository.initializeQuestionBankIfNeeded()` 将基础精选核心题库自动载入 Room `bank_questions` 数据表。
2. **在线更新机制**：
   - 当用户在「知识题库」界面点击“在线更新题库”时，触发 `syncOnlineQuestionBank()` 协程任务。
   - 系统支持从远端 JSON / API 接口拉取最新研发题目，通过 `OnConflictStrategy.REPLACE` 策略原子化增量合并到本地数据库中，全程不阻塞 UI 并提供进度与提示反馈。
3. **学情自适应推荐联动**：
   - 个性化学习路径模块实时分析用户在本地各学科的答题历史，根据做题正确率动态从本地题库调取对应薄弱学科题目进行定向推题。
